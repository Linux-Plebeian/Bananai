# Installation
- PC
  - Run main.py

- RPI
  - Install Raspberry Pi OS Lite
  - Run "sudo raspi-config" and enable ARM64 I2C
  - Run install.sh to install dependencies
  - Run "sudo -E python3 main.py" to start
